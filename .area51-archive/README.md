# Area51 standalone-transition archive

This branch preserves selected public GitHub history before any fork-network operation. It is an archive branch; the product remains on `main`.

Merged PR: [#59](https://github.com/aviatam/area51/pull/59). Main commit: `b635cd8fac4bd9620c9edc1659e8ae5d8293b9a6`; tested source tree: `b3f5f8c9ce4a5785dc96f0b7ba74a71a4f68e980`.

`github-metadata.json` contains all 59 PR/issue records, public PR descriptions, 59 comments and existing branch refs, plus references and verified digests for the test evidence. Authenticated account permissions, credentials and private security settings are deliberately excluded. GitHub's fork relationship is still intact.

Validation: 1,820 host tests and 174 container tests; automatic tool provisioning and ten-manager live OSV proofs on Linux, Windows and macOS; an actual two-turn LiteLLM agent followed by automatic VM quarantine; three fresh VM containment trials, separate-host recovery and acceptance passed on the fresh-host retry. The initial extended attempt hit an Incus missing-NVRAM startup failure.

This is a readable historical snapshot, not a way to restore original GitHub IDs, URLs, stars, watchers, secrets, settings or integrations. Four primary evidence ZIPs were separately preserved. Other artifact bytes and release binaries are not backed up here.

GitHub's official warning: [Detaching a fork](https://docs.github.com/en/pull-requests/how-tos/work-with-forks/detaching-a-fork). Leaving the fork network is permanent and may remove associated issues, PRs and other metadata. No repository deletion, recreation or detachment was performed.
